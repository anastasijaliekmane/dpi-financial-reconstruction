# DPI Financial Reconstruction

Static review application for case `DPI-HT-01`, reporting at 31 August 2026.

The application contains:

- the evidence register and 100 certified decisions;
- supporting schedules and three reconciled statements;
- `/review` for the compact assessor view and AI review trail;
- `/submission.json` for the machine-readable submission.

Serve the directory with any static web server. For example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.
